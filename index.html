04 Engineering practice

How I make software fast, safe and shippable.

These practices show up in every project above. Here's the detail behind them.

Performance & real-time

Fleet and utility users watch live data all day, so slow screens cost real operating time.

  • Cut live tracking for 1,600+ vehicle fleets from 20+ seconds to ~3 seconds by reworking how vehicle data is fetched and rendered.
  • Streamed telemetry over STOMP WebSockets for live instrument clusters (My Eicher, Control Tower) and real-time ITSM dashboards.
  • Rendered a POI heatmap of 7,000+ points in about a second on the Control Tower.
  • Implemented marker clustering three ways: Google Maps' default clusterer, custom clustering on Google Maps, and clustering on HERE Maps.
  • Used 85+ lazy-loaded modules in WFM/WHM and server-side rendering for the consumer portal to keep first loads light.

Security & compliance

Enterprise clients run VAPT audits, so security is part of the definition of done.

  • Led VAPT remediation on My Eicher: 15+ findings closed, and the application passed the audit.
  • Added HMAC-SHA256 request signing across My Eicher, VTS and Control Tower, with encrypted query parameters and secure document URLs.
  • Set up single sign-on with SAML 2.0/ADFS and Active Directory, and persona-based RBAC down to tab level.
  • Hardened apps with security headers, code obfuscation, dev-tools blocking, idle auto-logout, rate limiting and bcrypt hashing.

Release engineering

Predictable releases keep clients' production environments calm.

  • Own GitHub source control with GitFlow branching: feature, bugfix, hotfix and release branches.
  • Tagged 80+ semantic-versioned releases and wrote release notes for each.
  • Promote builds through dev → QA → pre-prod → production. The apps are containerized with Docker and Nginx and deployed by the DevOps team.
  • Review every pull request and enforce coding standards with ESLint and Prettier.

Modernization

Long-lived products need upgrades that don't stop feature work.

  • Migrated the entire Subscription Tool from MySQL to PostgreSQL, across all 150+ APIs.
  • Upgraded a 120+ module codebase from Angular 9 to Angular 15.
  • Moved repositories from GitLab to GitHub.
  • Replaced deprecated HERE Maps APIs across 10+ modules and removed hard-coded keys.

Leadership

  • Lead 5–8 engineers across 9 products, handling estimation, sprint planning, code reviews and delivery.
  • Run requirement sessions with Eicher and PGVCL teams and turn them into technical designs.
  • Drive QA and UAT cycles through to production releases and hotfixes, and own production support.
  • Mentor developers and review their code against shared standards.
